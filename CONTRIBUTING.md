# Contribuir a KisoDesk

1. Crea una rama desde la versión actual.
2. Mantén los cambios acotados y añade pruebas cuando cambies comportamiento.
3. Ejecuta en los proyectos afectados `npm run typecheck` o `npm run type-check`, `npm test` y `npm run build`.
4. Describe el cambio, su validación y cualquier requisito de entorno en el pull request.

No incluyas secretos, datos de producción, credenciales ni archivos generados.
